## 1. 至少三种 3D 打印材料

**PLA。** 打印温度大约 190–220 °C，热床 50–60 °C。好打、气味小、变形小，适合外壳和夹具。不耐热，暴晒或靠近电机容易变软，也偏脆。

**PETG。** 打印温度大约 230–250 °C，热床 70–80 °C。比 PLA 韧，耐温和耐潮更好，适合支架和需要一点弹性的结构件。容易拉丝，对挤出机温度更敏感。

**TPU。** 柔性材料，打印要慢，直接挤出机更好打。适合减震垫、保护套、卡扣。不能当主承力梁。

**ABS。** 更耐热，适合舱内靠近电子设备的零件。冷却时容易翘边，最好用封闭打印机。

机架受力件优先 PETG 或更强的尼龙、碳纤增强材料。外观件用 PLA 即可。

## 2. Bambu Studio 切片

1. 在 SolidWorks 里把零件另存为 STL 或 STEP。
2. 打开 Bambu Studio，选 H2D 和对应喷嘴。
3. 导入模型，放到热床上，底面贴盘。
4. 选材料预设，例如 PLA 或 PETG，不要用 PLA 预设打 PETG。
5. 层高常用 0.2 mm。受力件壁厚至少 3 层，填充 20%–40%。
6. 需要支撑的悬空面打开支撑。装配销孔尽量朝上，减少支撑留在配合面上。
7. 切片后看时间、耗材和有没有悬空警告，再导出发给打印机。

## 3. 拓竹 H2D 使用要点

按拓竹官网 H2D 说明操作：

1. 打印机放平，完成开机引导和校准。
2. 选择和切片一致的材料，插入对应料盘。
3. 热床清洁后，按材料选择打印板。
4. 先让打印机完成调平和对高，再开始任务。
5. 第一层不粘时停下，清洁热床或调整贴盘，不要等打印完再看。
6. 换材料时按机器提示回抽和清理喷嘴，避免堵头。

## 4. 嘉立创 3D 打印和机加

**3D 打印。** 在嘉立创 3D 页面上传 STL 或 STEP，选工艺（SLA 树脂或 SLS/MJF 尼龙等）、材料、颜色和数量。页面会给出价格和交期。确认壁厚和最小孔径能打出来，再付款。

**机加件。** 上传 STEP，选铝合金或其他材料、表面处理和公差。配合孔、螺纹孔要在模型里建好，并在备注里写螺纹规格。未标注的面按平台默认公差。下单前用装配体检查干涉。

小批量外观件和试装件走 3D 打印。要螺纹强度、平面度和重复装配的零件走机加。

## 5. 螺丝、螺母、螺柱

| 种类 | 用途 |
| --- | --- |
| 内六角圆柱头 | 机架最常用，沉进零件表面，扳手从上面拧 |
| 杯头 / 盘头 | 薄板固定，头部更扁 |
| 沉头 | 螺丝头与表面齐平 |
| 自锁螺母 | 有尼龙圈，防松 |
| 法兰螺母 | 自带垫圈面，压薄板 |
| 铜柱 / 尼龙柱 | 把电路板架高，两端都是螺纹或一公一母 |

规格看螺纹直径和长度，例如 M3×8 表示直径 3 mm、螺杆长 8 mm。碳板和打印件上 M3 最常见。拧入塑料时，螺丝长度不要顶到孔底。

安装方法：

1. 螺丝加螺母，从另一侧用扳手拧紧。
2. 螺丝拧进预埋铜螺母或攻好的螺纹孔。
3. 螺丝加弹垫和平垫，再加螺母，用来防松。
4. 双头螺柱两端各拧一个零件，用来隔开两块板。

## 6. 滑丝了怎么办

滑丝是螺纹被磨平，继续拧只会打滑。

1. 立刻停下，不要加大力。
2. 塑料件：换大一号螺丝，或加热埋入铜螺母，或在孔里滴螺纹胶后改用稍长螺丝。孔已经太大时，钻孔镶嵌螺母，或重新打印该零件。
3. 金属件：用丝锥回牙。牙已经没了就扩孔，改用大一号螺纹，或改成通孔加螺母。
4. 螺母滑丝就换新螺母，不要和滑丝螺丝继续配。
5. 碳纤维板不要在板里攻丝硬拧，滑丝后板会分层。改用通孔加螺母。

## 7. 碳纤维板固定螺丝，至少三种

1. **通孔加螺母。** 板上打光孔，螺丝从一面穿入，另一面用自锁螺母。这是最不容易把碳板拧坏的做法。
2. **通孔加预埋件或铝柱。** 在两块碳板之间用铝柱或铜柱隔开，螺丝只吃金属螺纹，碳板只受压。
3. **沉头通孔加背面螺母。** 需要表面平整时用沉头螺丝，背面仍用螺母，不在碳板本体上攻牙。
4. **夹板。** 碳板两面各垫一块打印件或铝片，螺丝夹紧这三层。适合孔边已经毛过、不能再扩的位置。

碳板钻孔要用锋利钻头，低转速，背面垫木板，防止出口分层。孔边毛刺用细砂纸轻磨，不要用力掰。
