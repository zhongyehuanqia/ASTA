## 1. 看懂接口

| 部件 | 常见接口 | 作用 |
| --- | --- | --- |
| 飞控 | USB Type-C | 烧录固件、连地面站、看日志 |
| 飞控 | UART（TX/RX） | 接 GPS、数传、图传、光流，两边 TX/RX 交叉 |
| 飞控 | I2C（SDA/SCL） | 外置磁力计、气压计，线要短 |
| 飞控 | CAN | 接 CAN 电调或 CAN GPS，需终端电阻 |
| 飞控 | PWM / DShot | 驱动电调，再由电调驱动电机 |
| 飞控 | SBUS / CRSF | 接收机输入，遥控器指令进飞控 |
| 雷达 | UART 或网口 | 输出距离或点云。UART 雷达看波特率，网口雷达看 IP |
| 载板 | 供电、USB、网口、串口 | 给机载电脑供电，并把飞控、相机、雷达接到电脑 |

接线时先对电压。飞控串口多数是 3.3 V，不能直接接 5 V 的 TX。

## 2. 微空飞控烧固件

手册：https://micoair.cn/zh/docs/flight-controller/firmware-tutorial

微空飞控可跑 ArduPilot、PX4、Betaflight、INAV。推荐用浏览器工具 MicoConfigurator，需要能传数据的 USB 线。

能正常开机时，用在线升级或本地烧录。第一次烧、固件起不来、或要换固件种类时，用 DFU：

1. 断开电池和 USB。
2. 按住 USB 口旁的 BOOT。
3. 按住的同时插入 USB。
4. 上电约 2 秒后松开。
5. 在 MicoConfigurator 的 DFU 页面选择和板子完全一致的型号再烧。

型号不能混。MicoAir743 的 PX4 目标是 `micoair_h743`，v2 是 `micoair_h743-v2`。烧错目标会找不到传感器。

PX4 也可以用 QGroundControl：打开 Firmware，USB 连接飞控，选自定义固件，烧 `.px4` 文件。烧之前先在地面站里备份参数。

## 3. QGroundControl 重要参数和校准

安装：https://docs.qgroundcontrol.com/master/en/qgc-user-guide/getting_started/download_and_install.html

校准顺序按地面站左侧来，不要跳：

1. 机架 Airframe。多旋翼选和实物一致的机型。微空板要选对应的板级目标，不要用别的板的固件。
2. 传感器。陀螺仪静置；加速度计按画面把飞机转到六个面；磁力计远离金属和电脑，绕满各个方向；水平校准把飞机放平。
3. 遥控器。每个通道拨到最大和最小，确认俯仰、横滚、油门、航向方向没有反。
4. 飞行模式。至少留手动/自稳、定点、返航。
5. 电源。测电压、电流，填电池节数和容量。
6. 电调和电机。不装桨，确认电机转向和机架图一致。转向反了就对调该电机的三根动力线里的任意两根，或在地面站里反向。

常用参数：

| 参数 | 作用 |
| --- | --- |
| `SYS_AUTOSTART` | 机架编号，决定默认参数 |
| `COM_RC_LOSS_T` | 遥控器丢失多久后触发失控保护 |
| `NAV_DLL_ACT` / `COM_LOW_BAT_ACT` | 遥控器丢失、低电压时是返航、降落还是悬停 |
| `BAT1_N_CELLS`、`BAT1_V_CHARGED`、`BAT1_V_EMPTY` | 电池节数和电压范围 |
| `MPC_XY_VEL_MAX`、`MPC_Z_VEL_MAX` | 水平、垂直最大速度 |
| `MC_PITCHRATE_MAX`、`MC_ROLLRATE_MAX` | 最大角速度，太大容易晃 |

校准后先不装桨，解锁看电机，再装桨低空悬停。

## 4. ROS 里这几样怎么连

本目录 `ros_ws` 是一个最小例子。

- `package.xml`：包的名字和依赖。这里依赖 `rospy`、`std_msgs`、`message_generation`。
- `CMakeLists.txt`：告诉 catkin 去编译 `msg/Detect.msg`，并安装 Python 节点。
- `msg/Detect.msg`：自定义消息，字段是类别名和像素坐标。
- `scripts/detector.py`：一个 node。它发布 topic `/detect`。
- `scripts/printer.py`：另一个 node。它订阅 `/detect`。
- `launch/demo.launch`：一次启动两个 node。

数据流是：detector 节点把检测结果放进 `/detect`，消息类型是 `week2_demo/Detect`，printer 节点收这条消息并打印。

```bash
cd ~/桌面/第二周任务/ros_ws
source /opt/ros/noetic/setup.bash
catkin_make
source devel/setup.bash
roslaunch week2_demo demo.launch
```

另开一个终端：

```bash
source ~/桌面/第二周任务/ros_ws/devel/setup.bash
rqt_graph
```

图里应看到 `/detector` 经过 `/detect` 连到 `/printer`。

## 5. 视觉模型各做什么

| 工具 | 适合做什么 | 不适合拿来做什么 |
| --- | --- | --- |
| YOLO | 在一张图里找出多个物体，给出框、类别和置信度。机载实时检测常用小模型，如 `yolov8n` | 不直接做像素级颜色阈值，也不负责飞控 |
| OpenCV | 读图、改颜色空间、阈值、找轮廓、画框、标定相机。颜色标记、降落靶适合先用它 | 它不是一个训练好的检测模型 |
| OpenMV | 带摄像头的小单片机，直接在相机上跑颜色识别和简单追踪，结果用串口发给飞控 | 算力小，不适合大模型或高分辨率多目标 |

关系可以记成：OpenCV 负责把图像处理成可用的结果；YOLO 是在电脑或载板上跑的检测模型，内部也会用到 OpenCV 画框；OpenMV 是把相机和简单视觉算法做在一块小电路板上。
