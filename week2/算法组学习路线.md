# 算法组第二周：ROS、PX4、视觉

硬件装配、3D 打印和螺丝不在算法组任务里。本周按下面三块学。

## ROS

目的：看懂 topic、msg、node、launch、CMakeLists、package.xml 怎么连在一起。

本机例子在 `ros_ws`。`detector` 发布 `/detect`，消息类型是 `week2_demo/Detect`，`printer` 订阅它，`demo.launch` 把两个节点一起启动。

```bash
cd ~/桌面/第二周任务/ros_ws
source /opt/ros/noetic/setup.bash
source devel/setup.bash
roslaunch week2_demo demo.launch
```

另开终端：

```bash
source ~/桌面/第二周任务/ros_ws/devel/setup.bash
rqt_graph
```

## PX4

先会讲结构，再会上地面站。

- 源码在 `~/PX4-Autopilot`。框架图在 `~/桌面/algo-week1/px4/framework.md`。
- 状态机：`src/modules/commander/`，看 `arming_state` 和 `nav_state`。
- 对外通信：`src/modules/mavlink/`。模块之间用 uORB，消息在 `msg/`。
- 250 是机架参数：`ROMFS/px4fmu_common/init.d/airframes/4050_generic_250`。
- 微空飞控烧录用 MicoConfigurator：https://micoair.cn/zh/docs/flight-controller/firmware-tutorial 。PX4 目标名要和板子一致，743 是 `micoair_h743`，v2 是 `micoair_h743-v2`。
- QGroundControl 校准顺序：机架、传感器、遥控器、飞行模式、电源、电机转向。实机校准要等飞控接到电脑上再做。

## 视觉

| 工具 | 算法组里用来做什么 |
| --- | --- |
| OpenCV | 读图、HSV 颜色分割、找轮廓、算目标中心。降落靶、色块先用它 |
| YOLO | 多类目标检测，输出框和置信度。已经在 `algo-week1/vision/detect.py` 跑通过图片、视频和 USB 摄像头 |
| OpenMV | 摄像头和简单识别做在一块小电路板上，结果用串口发给飞控。电脑上不跑它 |

颜色识别练习：

```bash
python3 ~/桌面/第二周任务/opencv_color.py
```

视觉仿真降落已经跑通，代码在 `视觉仿真/vision_land.py`。
