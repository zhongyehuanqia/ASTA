# ROS、PX4、视觉

按内容分目录。打开文件夹就能看出里面写的是什么。

| 目录 | 内容 |
| --- | --- |
| `笔记/` | 学习笔记、软件笔记、硬件笔记、学习路线，以及 Git 截图 |
| `yolo检测/` | YOLO 图片、视频、摄像头检测，训练配置和检测截图 |
| `颜色识别/` | OpenCV 用 HSV 找蓝色和红色色块 |
| `仿真降落/` | 仿真里用朝下相机找蓝色地面靶，飞到上方再降落 |
| `ros/src/detect_demo/` | 检测结果话题：自定义消息、发布节点、订阅节点、launch |
| `px4/` | PX4 状态机、通信和 250 机架的框架笔记 |

仓库地址：https://github.com/zhongyehuanqia/ros-px4-vision
